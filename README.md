# 🖐️ AI Gesture-Controlled PC (Webcam Virtual Controller)

Apne PC ke **Webcam** se haath ke gestures detect karke poora PC control karne wala Python project.

---

## 🚀 Features (Kaise Kaam Karta Hai?)

| Gesture | Action | Description |
| :--- | :--- | :--- |
| ☝️ **Sirf Index Finger UP** | **Move Cursor** | Mouse pointer index finger ke tip ko follow karega smoothly. |
| 🤏 **Thumb + Index Pinch** | **Left Click** | Index finger aur Thumb ko milane par single Left Click hoga. |
| 🤏 **Thumb + Middle Pinch** | **Right Click** | Middle finger aur Thumb ko milane par Right Click hoga. |
| ✌️ **Index + Middle UP** | **Scroll Mode** | Haath upar karne par Page Scroll Up, neeche karne par Scroll Down. |
| 🤙 **Pinky + Thumb + Index UP** | **Volume Control** | Thumb aur Index ke beech ki doori se Windows System Volume kam/zyada hoga. |
| ✊ **Fist (Mutthi / All Down)** | **Drag & Drop** | Left mouse button hold ho jayega files ko drag karne ke liye. |
| 🖐️ **Open Palm (5 Ungliyan)** | **Standby** | Cursor freeze ho jayega taaki haath aaraam se move kar sakein. |

## 🛠️ Setup Instructions (Run Kaise Karein?)

```bash
cd C:\Users\mrkr7\.gemini\antigravity\scratch\gesture_controlled_pc
```

```bash

```

### 3. Application Run karein:

